# Bingo - Java Swing

Proyecto de Bingo desarrollado en Java con interfaz gráfica Swing para Visual Studio Code.

## Archivos

- `src/Bingo.java` - interfaz gráfica y control del juego.
- `src/Tabla.java` - generación y validación de las tablas de Bingo.
- `src/Cantor.java` - generación y control de las balotas.

## Requisitos

- JDK de Java instalado.
- Visual Studio Code con soporte para Java.

## Ejecutar

Abre el proyecto en Visual Studio Code y ejecuta `src/Bingo.java`.

También puedes compilar desde una terminal ubicada en la carpeta `src`:

```bash
javac *.java
java Bingo
```

No requiere librerías externas; utiliza Java Swing.
